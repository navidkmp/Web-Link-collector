# 🕸️ Web Scraper

A lightweight web scraping application built with **Python and Django**, designed to extract and present website data through a clean and intuitive interface.

## ✨ Features
- Simple and intuitive user interface
- Website data extraction
- Clean and responsive design
- Built with Django

## 🛠️ Tech Stack
- Python
- Django
- HTML5
- CSS3
- Bootstrap

## 🔗 Links
- **GitHub:** [Repository](https://github.com/navidkmp)

## ⚙️ Getting Started

```bash
git clone https://github.com/navidkmp/Web-Link-collector
cd web-scraper
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
